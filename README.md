## ⚙️ Arquitetura e Destaques Técnicos

Este não é apenas um site estático. Aproveitei este projeto para demonstrar práticas de automação, consumo de dados dinâmicos e CI/CD, unindo meu background técnico com o desenvolvimento visual:

*   **Integração com GitHub API:** A seção de projetos do portfólio não é estática. A aplicação consome a API REST pública do GitHub para buscar, filtrar (via *topics/tags*) e listar dinamicamente meus repositórios mais relevantes, garantindo que o site esteja sempre atualizado sem necessidade de commits manuais.
*   **Deploy 100% Automatizado (CI/CD):** O fluxo de build e publicação está configurado com **GitHub Actions**. Qualquer push na branch `main` engatilha a esteira que realiza o build da aplicação React e faz o deploy diretamente para o GitHub Pages.
*   **Dark Mode Nativo:** Lógica implementada no frontend para respeitar e salvar a preferência de tema do usuário.

## 🛠️ Tecnologias Utilizadas

*   **Infraestrutura & Automação:** GitHub Actions, GitHub Pages
*   **Gerenciador de Pacotes:** npm
